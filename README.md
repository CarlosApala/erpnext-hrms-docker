# erpnext-hrms-docker

Imagen Docker de Frappe v16.53.0 + ERPNext v16.52.1 + HRMS v16.52.0 (imagen basada en frappe_docker).
Se construye con GitHub Actions y se publica en `ghcr.io/carlosapala/erpnext-hrms-docker`.
Para actualizar versiones: editar `apps.json` y `FRAPPE_VERSION`/`TAG` en el workflow.
